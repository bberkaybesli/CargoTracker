# 📦 CargoTracker

Basit ve etkili bir kargo takip uygulaması. JSON veri yapısı üzerinden gönderi takibi yapılmasına olanak tanır.

---

## 🚀 Proje Hakkında

Bu uygulama, bir takip numarası girilerek kargonun hangi aşamada olduğunu, çıkış noktasını, varış noktasını ve güncel durumunu görüntülemek için tasarlanmıştır.

### ✨ Özellikler
* **Takip Sorgulama:** Takip numarası ile anlık veri çekme.
* **Veri Görselleştirme:** Kargo bilgilerinin (çıkış/varış noktası, durum) düzenli listelenmesi.
* **Hafif Mimari:** Karmaşık kütüphaneler yerine saf JavaScript ve JSON tabanlı yapı.

---

## 🛠️ Teknolojiler
* **Frontend:** HTML5, CSS3, JavaScript
* **Veri Yapısı:** JSON (data.json)
* **Sunucu:** Node.js (index.js üzerinden yönetim)
